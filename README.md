# 🚗 SchoolPool
## A Secure Smart Carpooling Platform for School Children

SchoolPool is a secure and intelligent carpooling platform designed to manage and safeguard the daily school commute of children. The platform connects verified parents from the same locality whose children attend the same school, enabling safe, organized, and transparent ride sharing.

This project aims to reduce traffic congestion, transportation costs, and safety concerns by using modern web technologies such as real-time GPS tracking, JWT authentication, digital attendance, emergency alerts, and structured ride scheduling.

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Mahesh1055/SchoolPool.git
cd SchoolPool
```

## 2️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

## 3️⃣ Backend Setup

```bash
cd backend
dotnet restore
dotnet run
```

## 4️⃣ Database Setup

- Install PostgreSQL
- Create Database: `SchoolPoolDB`
- Update the database connection string in `appsettings.json`
